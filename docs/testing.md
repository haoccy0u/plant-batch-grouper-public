# 测试与交付验证

## 默认合成回归

```console
python scripts/test.py --blender /path/to/blender
```

默认执行图几何、边界情况、GRAPH流程、LEGACY流程、局部茎片变化、官方插件生命周期与安装验证。所有场景在独立后台 Blender 中生成，不访问当前用户工程。每次运行新建 `.test-results/<run-id>/`；汇总只接受本次子进程的报告，失败、跳过和通过分别记录。

构建不需要 Blender，使用标准库即可：

```console
python scripts/build.py
```

构建校验所有插件源码可编译、ZIP完整性和单层包目录。ZIP只包含插件Python文件及完整LICENSE，换行和时间戳固定，适合重复构建验证；同时输出SHA256文件。

## 可选历史资产

```console
python scripts/test.py --blender /path/to/blender --real-fixtures /path/to/archive
```

归档根保留原有 `backups/` 和 `test_artifacts/` 相对布局。历史测试覆盖旧记录迁移、坐标/拓扑/UV/颜色/材质/法线校验、最后一组合并和破坏注入回滚。资产不随 Git 分发；未指定或缺少对应文件时显示 SKIP，不算通过。测试输出仍写本次临时目录，不覆盖输入模型。
