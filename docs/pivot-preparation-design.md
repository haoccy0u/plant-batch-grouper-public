# v2.3.2 草本枝条原点与生长方向

状态：v2.3.2 正式发布设计。直接接受点击确认时的模型、原点和完整坐标轴，并调整根部支持采样。用户已完成原点整理与后续烘焙流程的现场验证；发布整理仅静态审查、语法和打包检查。自动判断仍需结合实际资产校准，不宣称准确率或自动处理率提升。

适用于已经整理成独立枝条的草、芦苇和草本花卉。目标是根部原点、沿生长方向的局部 **+X**、单位缩放和保留世界几何，为后续手动使用 Game Tools Object Attributes／Pivot Painter 2 做准备。本轮不改原分组算法，不新增灌木层级、自动烘焙、自动导出或 Unreal 材质。

## 1. 集合与完成流程

独立面板为“原点与生长方向”。待处理集合留空时沿用 Set Up 的输出集合；完成集合可选择已有集合或输入名称新建。两个集合不能相同或互相嵌套。来源备份不参与原点准备，原分组的归属、完成记录与编号不变。

流程为：

**指定待处理和完成集合 → 自动设置并归档 → 在视口逐根选择剩余对象 → 原生编辑原点与轴 → 确认并归档隐藏。**

“自动设置并归档”直接处理根部与有向 +X 都可靠的对象，不再先展示一整株自绘根尖预览。成功对象移入完成集合，移除原集合关联并隐藏；其他枝条继续待处理。已开始人工编辑的对象不由自动步骤覆盖。

完成集合默认隐藏，提供“显示完成集合／隐藏完成集合”。完成以成功归档记录为准，普通隐藏或局部视图不算完成。失败对象保留原处，批次中已成功的对象保留进度。

旧 APPLIED 记录与当前对象数据一致时只归档，不再次重基。记录不匹配的对象保留当前状态并转人工确认。此处说明升级规则，不代表所有旧工程已完成兼容性验收。

## 2. 原生手动编辑

手动区有三个主要按钮：

| 按钮 | 行为 |
|---|---|
| 单独显示并编辑原点 | 隔离活动枝条，启用 Only Origins、本地变换方向、原生旋转工具与对象轴 |
| 确认并移入完成集合 | 接受当前模型、真实原点和完整旋转框架；必要时规范化正缩放，归档并隐藏 |
| 返回剩余视图 | 保留尚未确认的调整，退出本工具的隔离并恢复之前的编辑设置 |

首次进入可采用可靠的自动部分：只确定根部就只调整原点，只确定方向就保留当前原点、调整方向；两者都不明确时保留当前框架。用户在物体模式中用 Blender 原生移动、旋转工具修正，不需要填坐标或操作插件端点按钮，不创建持久编辑基准。

再次进入已开始人工处理的枝条时，保留当前原点和旋转，不重新覆盖。确认采用当前完整 XYZ 框架，不能仅根据 +X 重新选择滚转角。用户也可在插件之外调整模型或原点后直接确认，不要求先进入本工具的编辑模式。用户在视口选择下一根，插件不自动跳组。

进入前记录仅影响原点开关、变换坐标系、工具、坐标轴显示、Gizmo 和局部视图等设置。完成、返回及卸载时恢复；撤销／重做、保存重开后的衔接仍须用户验收。

### 确认以当前数据为准

点击确认即接受此时的网格、原点和完整坐标轴，包括用户已经修改的世界形状、法线、拓扑、UV、颜色和材质。不再与进入编辑时的旧数据比较，不要求建立或重建基准。旧工程中已有的基准记录兼容保留，但不作为确认门槛，也不用于恢复旧模型。

当前框架已经单位正交时，直接归档，不替换网格或矩阵。只有需要规范化非单位正缩放时，才以点击确认瞬间的当前数据建立本次事务比较起点，严格验证本次转换前后的对应世界数据；不能用旧手动会话的局部几何摘要拦截确认。

仅在复制对象导致准备身份冲突时，显示“为副本建立独立记录”。该入口只解除原点准备记录的身份冲突，不修改模型、原点、坐标轴或原分组 ID，不再提供重建模型基准的步骤。

确认失败时回滚本次确认的网格替换、变换、集合和进度，回到点击确认时的状态，保留此前人工修改。

## 3. 茎证据与自动判断

### 有效保存记录优先

优先使用有效保存的根端／方向及可信茎身份。来源记录必须与当前相关茎的顶点、拓扑和连接边界对应，不能只凭名称或对象原点认定有效。结果已变换时，证据从结果局部空间映射到当前世界空间；不直接套用隐藏来源备份的旧世界坐标。

输出局部茎快照只核验相关茎，不用整个输出的几何摘要作为身份门槛。独立叶片移动、修改或删减不应使未变的茎证据失效。索引改变时只在可证明唯一一一对应后恢复；坐标匹配不唯一、新增跨部件连接或茎拓扑改变时拒绝旧证据。

旧结果没有局部快照时，尝试验证来源到结果的完整顶点／拓扑对应。无法证明时使用结果自身的细长连通片；缺历史身份不等于必须人工。有效的旧人工判断优先保留，不能被生长轴规则反向覆盖。

### 根部和有向 +X 分开评估

沿现有网格边运行加权路径估计，用截面中心序列描述茎形状，不宣称得到精确中轴。端部以多个支持带估计根截面中心；边和面交线插值用于稀疏卡片，不直接把极端角点当根中心。

贴合的茎卡组成候选簇，按茎卡等权，避免顶点多的卡片占更大权重。不贴合候选分别评估。细小、退化或非主茎连通片不应直接否决明确主茎。

v2.3.2 要求每张卡片至少两次有效支持估计；可靠根部均值只使用有效估计，先卡内平均，再对卡片等权平均。卡内采样稳定性与卡间沿生长方向的根部错位仍使用严格的根部容差；卡片的横向偏置单独使用既有配对容差。多个不同候选簇仍按原有严格规则比较，方向判断和数据校验容差均不放宽。

没有可信茎身份时，先按以下主茎规则筛选：

1. 沿生长轴覆盖至少为最大茎候选覆盖的70%；花头和普通叶片包围盒不充当这个分母。
2. 保留基部最低附近的候选，基部容差为 max(0.5 × 茎宽, 0.02 × 茎长)。
3. 唯一候选继续判断；多个主要候选只在根点／方向各自一致时形成可靠结论。不把不相容候选的根尖平均成虚拟枝条。

根部可靠性与方向可靠性分别输出。相关初值如下：

| 判断 | 初值或条件 |
|---|---|
| 端部支持带 | 以 max(0.02 × 路径长度, 1.5 × 茎宽) 为基础，使用多个邻近尺度复估 |
| 每卡有效支持 | 至少两次；失败估计不参与可靠根部均值 |
| 卡内有效根点估计 | 最大两两距离不超过 max(0.2 × 茎宽, 0.005 × 茎长)，并保留数值精度下限 |
| 配对卡片根部沿轴错位 | 使用原有严格根部容差 |
| 配对卡片根部横向偏置 | 使用既有配对容差 max(0.5 × 较大茎宽, 0.02 × 较大茎长) |
| 多次有向方向估计 | 最大夹角不超过3°，不能把正反方向视为相同 |
| 近水平且无有效根端依据 | 生长轴投影差不超过路径长度2%时，需要确认正向 |
| 明显回弯 | 根尖弦长小于路径长度50%时，需要检查总体方向 |
| 零长度或无效框架 | 不允许应用 |

自动 +X 使用根到尖的总体方向；**精确茎尖定位不是独立通过条件**。根点仍不稳定时也可能保留可靠方向；方向冲突时也可能保留可靠根点。只有两项都可靠才自动归档，否则进入原生手动处理。

这些数值和路径估计需用户以已知根部的稀疏茎卡、曲茎和真实植物校准。本轮没有运行这些样例，不报告准确率或自动处理率提升。

## 4. 变换与数据校验

自动准备第一次建立框架时，X 为有向生长轴；在世界 Z、Y、X 中依次选与 X 最不平行的辅助轴，构造右手正交 Y、Z。有效保存框架优先复用。手动确认使用用户当前完整旋转框架，不按世界辅助轴重新定义滚转角。

手动确认时，当前已是单位正交框架的对象不进入重基路径，网格和矩阵保持不变，直接归档。以下转换适用于自动准备，以及手动确认时确实需要规范化的非单位正缩放。

记操作开始时的当前世界矩阵为 M，目标矩阵为 N，私有网格坐标按 **v_new = N⁻¹ M v_old** 转换。目标 N 具有确认的原点、右手单位旋转；正缩放转入网格。仅在副本校验通过后换入原对象，并再次按对象实际世界矩阵复核，防止变换通道分解产生的误差被忽略。

捕获全部解码角点法线，包括自动平滑和自定义法线：先用 M 的逆转置得到世界法线，再转到目标局部框架。Blender 5.1 路径使用浮点角点法线；其他版本只有实际校验通过才允许提交。此实现路径尚待本轮功能验收。

| 项目 | 固定校验要求 |
|---|---|
| 世界顶点 | 对应顶点每分量绝对误差不超过1e-7 Blender单位 |
| 世界角点法线 | 单位法线每分量误差不超过5e-5 |
| 拓扑 | 顶点、边、面和角点数量及对应、面绕序完全保留；不焊接、不重三角化 |
| UV、颜色、材质等 | 对应图层、域、值、活动图层、权重、面材质与对象材质引用保留 |
| 最终框架 | 单位轴长度、正交性、正行列式和对象缩放以1e-6容差检查 |
| 原点／方向 | 原点与目标每分量差不超过1e-7；+X与目标方向每分量差不超过1e-6 |

大坐标或其他条件下达不到容差就失败保留，不自动放宽。本次规范化的比较起点是确认瞬间的当前数据，不是进入手动编辑之前的旧模型。

只处理可编辑本地静态网格。父子、约束、修改器、动画／驱动、形态键、负／零缩放、非单位 Delta Scale、剪切或非有限数据被阻止；不自动解除或应用这些状态。共享网格先独立化，其他用户不应被修改。归档还检查其他场景共享和只读集合关联。

每个批次设计为一个 Blender 撤销操作；单对象事务失败不清除其他成功进度，不自动保存工程。使用 Object／Generated 坐标或变换相关程序材质的外观需要用户另行检查，不能从 UV／材质引用保留推断任意着色表现不变。

## 5. 进度、归档与升级

准备记录独立保存在场景中，按对象稳定标识关联。当前记录包括分析依据、根／方向可靠性、原点编辑状态、采用当前数据的确认策略、成功后的完成集合与校验统计。新手动流程不创建持久网格基准；旧基准字段可缺失或兼容保留，不拦截确认。旧版本1记录延迟接续到版本2，读取本身不移动集合或重设原点。

成功状态 DONE 与完成集合关联用于隐藏及防止重复处理。旧 APPLIED 且与当前数据匹配时直接归档；旧未应用的有效人工根端也须保留。普通选择、隐藏或改名不代表完成，也不重写原分组身份。

合并阶段保存的 PBG_PivotSource 仍记录输出局部茎顶点对应及拓扑。准备成功后同步局部来源坐标；不可验证的旧证据不能被强行重新盖章为可信。原点准备不改分组会话的识别参数、人工归属、来源备份和结果编号。

## 6. Game Tools 0.3.2 兼容约定

以本机 Object Attributes 实现为依据，不将 Data Baker 的同名选项视为相同：

- Position 读取求值世界矩阵；Object Attributes Axis 直接读取指定矩阵轴，未归一化。Extents 同样沿未归一轴投影，因此残留缩放会额外放大长度。准备后的单位框架用于避免这一风险。
- 默认 PivotPainterDefault 的 AxisExtents RGB 使用Y，A的Extents使用X。后续应由用户将 **RGB三个Axis设X、A的Extents设X**，并与实际UE材质解码核对。
- Extent 取完整枝条网格相对原点沿所选轴的最大绝对投影，可能由花头或叶尖决定；它不是茎弧长或自动识别的根尖弦长。
- 默认单位倍率100、翻Y、XYZ轴顺序，另翻转纹理行／UV V。方向及extent使用 S M S，不能笼统解释为只翻世界Y，也不应额外手动再翻一次。
- 非XYZ设置只重排extent轴向量、没有同步重排点，存在需要单独核对的风险。首轮后续联调固定XYZ、仅翻Y、不翻X/Z、REL_WORLD及origin_obj=None。
- 自定义Origin会带入完整位置、旋转和缩放；其他轴序、符号或Origin配置均单独待验收，保留用户现有配置。
- scene单位倍率不会自动乘入纹理的unit_scale，而内置FBX导出启用apply_unit_scale。先以scene scale 1与100倍换算核对纹理和网格实际尺寸；其他单位另验收。

插件不调用会覆盖现有纹理配置的默认预设，不修改路径、覆盖选项或单位，也不自动烘焙、导出。独立草枝无需为此强建灌木层级。

## 7. 本版验收与回归场景

用户对 v2.3.1 已给出基本达到要求的反馈。下表列出 v2.3.2 新行为及相关回归关注点，不是本版已通过测试报告。本轮不启动独立后台功能测试，也不替用户在当前工程执行这些操作。

| 场景 | 应观察到的行为 |
|---|---|
| 明确单茎及贴合双卡 | 自动设置、归档隐藏；采样密度差异不偏向顶点多的一片 |
| 根部与方向只明确一项 | 保留可靠部分，另一项由原生工具修正；不因精确tip不稳定一律否决 |
| 多主茎、水平或明显回弯 | 冲突项待人工；有效保存根端／方向优先 |
| 旧 APPLIED 记录 | 有效记录只归档；不匹配项保留并提示检查 |
| 独立叶片编辑 | 未变茎证据仍可使用；确认接受当前修正后的完整模型，不要求重建基准 |
| 原生移动／旋转原点 | 模型世界位置及法线保持，完整旋转框架可由用户调整 |
| 暂退、再进入及切换枝条 | 保留调整，恢复进入前工具与局部视图，不自动跳组 |
| 未先进入插件编辑，直接确认 | 接受当前模型、原点与完整轴向；无旧基准也可完成 |
| 单位正交框架确认 | 直接归档，不替换网格或矩阵 |
| 实际网格改变或旧基准不符／缺失 | 接受当前数据，旧基准不拦截、不恢复旧模型 |
| 复制身份冲突 | 仅显示“为副本建立独立记录”，不改原分组 ID |
| 每卡有效支持不足或根部错位 | 不能自动接受不可靠根部；不同候选簇与方向规则不放宽 |
| 正非均匀缩放及共享mesh | 单位框架、独立数据，世界数据达固定容差 |
| 不支持的对象条件 | 单独阻止；不自动改父子、形变或其他场景 |
| 部分失败、撤销／重做、保存重开 | 正确回滚及恢复进度、完成隐藏与工具设置，保留确认前人工修改 |
| Game Tools设置与后续烘焙 | 原设置完整；用户核对位置、方向、extent、单位和实际UE表现 |
