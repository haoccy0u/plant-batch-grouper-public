# 植物批量分组 2.2.1 · 操作说明

工作流：**Set Up → 选择识别方式 → 分析分组 → 合并无歧义部分 → 在视口逐片修复**。

## 安装与切换

在 Blender“偏好设置 → 插件 → 从磁盘安装”中安装 `plant_batch_grouper_v2.2.1.zip`，并勾选启用。在 3D 视图按 N，打开“植物分组”。开发更新先运行 `scripts/build.py`，再在 Blender 文本编辑器运行 `scripts/install.py`，同样使用正式安装与启用流程。

本版修复了启用失败后面板仍残留的问题。旧会话遇到该问题时，先保存工程副本，再运行上述安装脚本。脚本会清理本插件的旧注册并保留集合设置和进度，不自动覆盖工程。

“自动分组”增加了 **识别方式**：

- **连接图**：沿现有网格边计算路径，用局部宽度、路径配对、连接端到表面的距离和方向判断连接。侧枝沿连接图寻找主枝，叶片附着在枝干上；不会通过叶片把两根枝条连起来。多个接近的候选保留给人工选择。
- **原识别**：保留 2.1.1 的生长轴、根部、茎片配对算法。

选择方式后点击 **分析分组** 才生效。已有工程仍按保存的方式继续，升级不自动重新分组。局部刷新与合并使用当前分析记录的方式；面板若显示切换提示，说明所选方式尚未用于分析。

两种方式面向草、芦苇和草本花卉，按实际模型选择。用户测试中，芦苇更适合连接图，花朵模型更适合原识别；这不是所有模型的固定分类规则。灌木不属于当前支持与优化范围。

比较两种方式时，请从同一份未合并模型副本分别开始。已完成的输出会被保护，切换方式不会拆掉或重新生成这些输出。

## Set Up

指定来源集合和输出集合，两者不能相同或互相嵌套。输出集合可直接选择，或输入名称后点击“创建”。

结果名称为前缀直接拼接数字，如 `Flower_`、起始编号 `1`、三位数字得到 `Flower_001`。所有批次写入指定集合，连续编号、跳过重名，失败不消耗编号。

**参考枝条不是训练样本。** 原识别中只参与有限的茎长度阈值调整；连接图中仅记录形状，不自动拟合一套参数。两种方式都在本地计算，运行时不需要语言模型、网络或额外模型服务。

## 自动分组

1. **清理无面对象（可选）**：删除来源及子集合中整个对象都没有面的本地网格，支持撤销。不删除正常网格内部的孤立点。参考对象、结果、已完成组原件、只读及跨范围共享对象跳过。仅此按钮会主动删除原件。
2. 选择识别方式，点击 **分析分组**。首次使用、增加来源对象、修改全局参数或更换方式时执行。
3. **合并无歧义部分**：刷新判断并输出明确枝条。单对象复制，多对象 Join，不焊接顶点；成功后隐藏原件与输出。手动修复后可再次使用。

跳过清理时，分析忽略零面对象并在预览中暂时隐藏；它们新增真实面后，局部刷新可重新纳入。

## 手动修复

1. 在视口选择红色叶片、花头或有歧义的侧枝。
2. 点击候选枝条。此时只预览，活动部件不变，也不写入归属。
3. 点击 **确认归属**。同枝还有问题时先保留判断；整根明确后显示 **确认并合并**，完成并隐藏。
4. 返回全部剩余内容，由用户自己选择下一片。切换活动对象后，旧候选绑定失效。

**局部刷新** 始终在手动修复面板中。移动、旋转、缩放或编辑部件后，退出编辑模式即可刷新；确认和合并前也自动刷新。会保留人工归属、组号与无关组的确认状态。无候选时，可修正连接位置后刷新。

连接图方式另有 **设为主枝**：当自动判断没有找出所需主枝，在视口选中确实属于主枝的完整对象后点击。该对象成为连接图的起点；已有配对主枝则保留原组，并记录人工确认。它不会切分网格，也不会拆掉已完成结果。指定的主枝随工程保存，重新分析时继续保留。

切换到连接图时，已有人工作出归属判断的旧组也保留组号与主枝集合。若新规则认为配对有疑问，会标为待检查，不自动覆盖人工决定。

“返回剩余视图”退出候选预览，不改变归属。“高级设置”可显示结果、退出着色预览、调整识别参数和导出报告。

## 范围与数据保留

- 连接图处理现有完整对象，不能把一个已连成整体的灌木网格自动切成各根枝条。含多个分离片段的对象仍作为整体待检查。
- 单主干连接多根一级侧枝时，主干保留为独立组，各一级侧枝及其后续附属部件分别分组；没有可信连接的部件保留待办，不强制连入最近枝。
- 极细长叶片与枝卡、严重重叠、缺少真实枝干、断裂或网格密度差异，仍可能造成角色判断或连接错误。可调整参数、人工指定主枝或修复位置，不保证全自动处理所有形态。
- 局部修改只重新提取变化对象的路径，连接图会重新搜索可达关系，并按判断变化标记相关组；大型场景仍可能耗时。刷新使用本次分析固定的尺度与参数。
- 合并校验以操作当时的世界坐标、UV、顶点色、材质和法线为准；失败撤回本批结果，保留原件、之前输出、人工判断和编号。完成的来源保留且隐藏。
- 工具不自动覆盖原工程。自行保存 `.blend` 会保存进度。结果默认隐藏且关闭渲染；导出时选择输出集合，渲染时自行切换来源与结果开关。

测试环境：Blender 5.1.0。运行方式与回归范围见 [测试说明](testing.md)。
