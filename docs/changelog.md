# 更新记录

## 2.3.2 — 正式公开发布 · 2026-09-22

- 手动移动原点后可直接确认；无需先进入插件编辑，不再要求建立或重建编辑基准。
- 确认接受点击瞬间的模型、原点和完整 XYZ 坐标轴，包括用户实际修正的网格数据。单位正交框架直接归档，不替换网格或矩阵；需要规范化正缩放时，仍按本次操作前后的当前数据严格校验并支持失败回滚。
- 新手动编辑不创建持久基准；旧基准记录兼容保留，不再拦截确认。复制身份冲突时仅显示“为副本建立独立记录”，不修改原分组 ID。
- 根部可靠判断要求每张卡片至少两次有效支持估计，可靠根部均值排除失败估计。保持卡内稳定性和卡间沿轴错位的严格检查，横向偏置单独使用既有配对容差；不放宽不同候选簇、方向或数据容差。
- 使用 GPL-3.0-or-later 发布，作者显示 haoccy0u / Codex；安装包附完整许可证与独立 SHA256 文件。
- 更新中文使用说明、烘焙与 UE 导入指南；记录当前环境中 Interchange 缺少 UV4、旧版导入成功的现象。
- 用户完成 92 枝条的原点准备、烘焙及旧版 UE 导入 UV4 的现场验证。发布整理仅做静态、语法和打包检查，不宣称全部边界场景、自动处理率提升或 UE 风摆材质已验收。

## 2.3.1 — 用户反馈基本达到要求

- 原点流程改为指定待处理／完成集合，明确枝条自动设置、校验、归档并隐藏；有效旧 `APPLIED` 记录只归档。
- 手动区保留“单独显示并编辑原点”“确认并移入完成集合”“返回剩余视图”三个主要按钮，使用 Blender 原生 Only Origins、本地旋转工具与对象轴；不再使用自绘根尖箭头或端点编辑按钮。
- 确认采用用户当前真实原点和完整旋转框架；返回和再次进入保留人工调整，退出时恢复原有编辑设置。
- 保存内部网格基准，按世界空间校验编辑前后数据。实际形状改变时暂停确认、保留改动，并提供重建基准入口。
- 根部和有向 +X 分开判断；多片茎卡等权，独立叶片变化不使未变的茎证据失效。判断阈值是待真实资产校准的初值，不声明准确率。
- 不修改原分组算法、来源备份、分组进度或 Game Tools 配置。
- 开发交付时仅做静态代码审查、语法和打包检查，没有运行独立功能测试；交付后用户反馈流程基本达到要求。该反馈不代表所有边界场景或后续烘焙均已验收。上述基准确认方式已在 2.3.2 改为接受当前数据。

## 2.3.0 — 历史开发版本

- 新增独立“原点与方向”面板：计算预览、交换根尖、3D 游标修正、单枝或批量应用。
- 优先从茎片恢复根尖；使用根部截面中心和根到尖的总体方向作为本地 +X。
- 原点准备使用独立持久化记录，保留分组完成记录和来源备份；合并结果补存输出局部茎来源。
- 在独立网格上转换并检查数据，再核对实际对象矩阵；失败回滚，支持撤销。
- 升级保留原点设置与进度，并清理预览回调。
- 本轮仅静态审查、语法编译和安装包检查，不运行独立功能测试；由用户在 Blender 中验收。
