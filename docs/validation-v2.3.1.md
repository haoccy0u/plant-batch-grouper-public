# v2.3.1 历史交付检查

环境：Blender 5.1.0 / Windows。该版本已由 v2.3.2 接续。

开发交付阶段完成原生编辑、集合恢复、单对象回滚、旧记录迁移及茎证据范围的静态审查；完成 Python 语法、差异格式、ZIP 完整性与安装内容核对。现场升级使用正式启用流程，保留对象、集合与进度，不覆盖保存原工程。

用户反馈该版原点流程基本达到要求。此反馈不代表全部边界场景或后续版本均已验收。按用户约定，交付时未运行独立后台 Blender 或功能测试。

该版的历史基准确认流程已在 v2.3.2 改为接受当前模型与原点，不再要求重建基准。具体旧场景记录、对象编号、诊断数据和工程副本保留在仓库外本地归档。

仍需由使用者结合资产验证撤销重做、保存重开、共享网格、异常变换与失败恢复。当前行为见 [原点操作说明](pivot-usage.md)。
