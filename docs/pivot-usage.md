# v2.3.2 原点与生长方向：操作说明

v2.3.2 支持手动移动原点后直接确认，也接受用户实际修正后的模型，无需重建编辑基准。用户已完成原点整理与后续烘焙流程的现场验证；发布整理只做静态、语法和打包检查，不代表所有边界场景均通过验收。插件不自动覆盖保存原工程。

## 自动完成一批

在侧栏“植物分组”中打开 **原点与生长方向**。

1. 指定 **待处理集合**。留空时使用 Set Up 中的分组输出集合。
2. 选择 **完成集合**，或输入新名称后点击旁边的加号。两个集合不能相同或互相嵌套。
3. 设置用于自动区分根尖的 **生长轴**，点击 **自动设置并归档**。

这一步会直接处理根部和有向 +X 都明确的枝条：设置根部原点及局部 +X、校验、移入完成集合并隐藏。完成集合默认隐藏，视口留下待处理枝条。已开始人工编辑的枝条保留当前调整，不被自动步骤覆盖。

算法分别判断“根在哪里”和“+X 朝哪里”。精确重建茎尖不是自动通过的必要条件；缺少历史茎身份也不会一律转人工。多个候选存在冲突时，保留可靠的部分供手动编辑使用。

本版根部判断要求每张茎卡至少两次有效支持估计，可靠根部的平均只使用有效估计。卡内不稳定、卡片沿生长轴错位仍严格检查；横向卡片偏置单独使用原有配对容差。多个不同候选簇、方向判断和数据校验容差没有放宽，不据此宣称自动处理率提高。

## 手动处理剩余枝条

在视口选中一根剩余枝条，使用三个主要按钮：

1. **单独显示并编辑原点**：隔离当前枝条，启用 Blender 原生 **仅影响原点（Only Origins）**、本地坐标系和旋转工具，并显示对象坐标轴。首次进入时可先采用可靠的自动根部或方向；再次进入会保留人工调整。
2. **确认并移入完成集合**：接受点击时的模型、真实原点和完整 XYZ 坐标轴。单位正交框架直接归档，不替换网格或矩阵；非单位正缩放规范化并通过校验后归档。成功后隐藏并返回剩余内容，用户自行选择下一根。
3. **返回剩余视图**：暂时退出隔离，保留尚未确认的原点调整，不自动跳到下一根。

编辑时，在物体模式下用原生旋转工具或 `R` 调整坐标轴，让局部 **+X** 指向生长方向；需要修正原点时用移动工具或 `G`。确认仅影响原点仍开启，观察模型世界形状保持原处。确认完成或返回剩余视图时，恢复进入前的工具、变换坐标系、仅影响原点设置和局部视图。

此流程不再使用插件自绘根尖箭头、交换根尖或 3D 游标端点按钮。

也可在插件编辑之外完成原点、方向或模型修正，直接点击 **确认并移入完成集合**。不要求先点击“单独显示并编辑原点”。

## 当前数据与确认失败

确认以**点击确认瞬间的当前数据**为依据，包括已经修改的网格形状、UV、颜色和材质，不再与进入手动编辑时的旧基准比较。新手动编辑不创建持久网格基准；旧工程的基准记录仍兼容，但不会阻止确认，也不会恢复旧模型。

如果当前框架已有单位缩放和正交坐标轴，直接移动到完成集合，不重新变换网格。需要把非单位正缩放转入网格时，使用临时副本，并严格比较当前数据与本次规范化结果的世界顶点、世界法线、拓扑、UV、颜色及材质。校验失败只撤回本次操作，保留点击确认前的人工调整。

仅在复制对象造成准备身份冲突时，界面显示 **为副本建立独立记录**。它解决原点准备记录的冲突，不要求重新建立模型基准，也不改变原分组 ID。

成功操作支持 Blender 撤销，处理进度随用户保存工程；插件不自动保存或覆盖工程。本次确认方式的撤销、重开和异常回滚仍需在 Blender 中验收。

## 旧记录与完成集合

- 有效的旧 `APPLIED` 记录只归档、隐藏，不重新计算或修改网格、原点和旋转。每条记录均须与当前对象数据匹配后才采用这条路径。
- 旧记录与当前对象不匹配时，保留现有模型，进入人工检查。有效保存的人工根端与方向优先沿用。
- **显示完成集合／隐藏完成集合**用于查看完成结果。完成状态来自成功记录，不因普通隐藏或隔离改变。
- 原分组的来源备份、分组决定与连续编号保持不变。原点归档只移动待处理的结果对象。
- 已验证的茎来源只检查相关茎顶点、拓扑和连接边界。独立叶片修改后，未改变的茎证据仍可用于重新判断根部和方向。

## 适用条件与判断初值

支持本地静态网格及正均匀、正非均匀缩放；共享网格会独立化。父子关系、约束、修改器、动画、形态键、链接数据、负／零缩放、剪切或非单位 Delta Scale 需要先由用户处理。与其他场景共享或涉及只读集合的对象不能直接归档。

自动判断使用的覆盖比例、根部距离、支持带和角度阈值需由用户结合真实资产校准；不承诺准确率或本版自动处理率提升。水平且缺少有效根端依据、明显回弯或主要候选冲突时，需要人工确认相应部分。

使用 Object／Generated 坐标或依赖对象变换的程序材质，表现可能随原点与坐标轴变化；请在 Blender 验收自己的材质。保留 UV、颜色和材质引用不能代替这项检查。

## Game Tools

烘焙仍由用户在 Game Tools 中执行。本工具不修改其纹理、预设、输出路径、单位设置，也不自动烘焙或导出。

本流程采用局部 +X 沿枝条长度。Game Tools 0.3.2 需核对 **RGB 三个方向通道的 Axis 都为 X，A 的 Extents 也为 X**；其默认预设使用方向 Y、长度 X。

Extent 是完整枝条网格相对原点的最大轴向投影距离，不是弯茎弧长。后续先由用户核对 XYZ、仅翻转 Y、world origin 的配置及单位；其他自定义组合仍待单独验收。详见 [设计与兼容约定](pivot-preparation-design.md)。
