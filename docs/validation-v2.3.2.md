# v2.3.2 发布检查与验证边界

日期：2026-09-22。环境：Blender 5.1.0 / Windows；烘焙联调使用 Game Tools 0.3.2、UE 5.8。

## 现场已确认

- 用户反馈分组与原点流程达到当前使用要求，并完成 92 根枝条的原点准备。
- 烘焙报告记录 92 个元素、10×10 数据贴图。对输出 FBX 的只读检查确认五套 UV，数据通道 UV4 含 92 个独立采样坐标。
- 同一 FBX 经当前 Interchange 流程导入时缺少 UV4，用户改用 UE 旧版 FBX 导入流程后确认 UV4 存在。
- 以上是本次现场反馈与文件核对，不代表所有模型、引擎版本或风摆材质已完成验收。

## 发布检查

本轮只执行源码静态审查、Python 语法检查、Git 差异格式检查、公开文件范围与本机路径检查、ZIP 完整性及许可证检查、从干净源码重建并比较安装包 SHA256。检查结果汇总在发布附件的 SHA256 和发布说明中。

发布包保留模块名及场景数据格式，作者显示与许可声明更新；原分组、原点计算及确认流程不因本轮整理改变。没有运行功能测试、后台 Blender 或操作当前 Blender / UE 工程。

旧开发包和诊断报告已本地归档。由于添加许可证和发布署名，正式包的 SHA256 与此前开发交付包不同，以同名 `.zip.sha256` 附件为准。

## 仍需按使用场景验收

- 撤销、重做、保存重开、旧工程接续和复制身份处理。
- 非单位缩放、共享网格、异常输入及回滚边界。
- 不同植物的自动根部与方向判断效果。
- UE 风摆解码、法线表现、变换、实例化与目标平台。
- Blender 4.2 等其他版本和非 Windows 平台。
